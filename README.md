# Choloo Jaai Documentation

## Overview

Choloo Jaai is an event management platform supporting:

- Concerts
- Music gigs
- Corporate events
- Seminars
- Conferences
- Symposiums

## Repositories

Frontend:
- choloo-jaai-frontend

Backend:
- choloo-jaai-backend

Documentation:

## Technology Stack

Frontend:
- Next.js
- TypeScript
- Tailwind CSS

Backend:
- NestJS
- PostgreSQL
- Redis
